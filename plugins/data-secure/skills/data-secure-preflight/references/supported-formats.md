# Supported formats

Local preflight supports PDF, DOCX, XLSX, PPTX, TXT, MD, CSV, PNG, JPEG and BMP. Scanned PDFs are supported when their JPEG page images can be extracted safely; otherwise they stop fail-closed. Image-only inputs and scan PDFs without a text layer require an explicit privacy profile because auto-detection cannot safely classify them before local OCR. Visual assets may be released only after automatic verification or explicit human review.
