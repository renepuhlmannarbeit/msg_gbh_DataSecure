# Sicherheitsgrenze

Der lokale MCP-Server verarbeitet die Dateien tatsächlich. Skills liefern Routing- und Governance-Anweisungen, können aber nicht garantieren, dass bereits in eine Claude-Unterhaltung hochgeladene oder eingefügte Inhalte vom Modell ungesehen blieben. Für eine Datenschutzverarbeitung vor dem Modell müssen Quelldateien über den lokalen Dateidialog oder den lokalen `Input`-Ordner eingehen.
