# Sicherheitsgrenze

Der lokale MCP-Server verarbeitet die Dateien tatsächlich. Skills liefern Routing- und Governance-Anweisungen, können aber nicht garantieren, dass bereits in eine Claude-Unterhaltung hochgeladene oder eingefügte Inhalte vom Modell ungesehen blieben. Für eine Datenschutzverarbeitung vor dem Modell müssen Quelldateien im Normalweg ausschließlich über den lokalen Betriebssystem-Mehrfachpicker eingehen. `Input` ist nur eine technische Inbox des ausdrücklich aktivierten IT-Supportmodus.

Die lokale Grenze besteht nur in einer Claude-Desktop-/Cowork-Sitzung, in der `data-secure-local` tatsächlich verbunden ist. Cloud-Cowork, Web, Mobil und geplante Cloud-Aufgaben dürfen keine Originale erhalten; ein sichtbarer Skill oder Plugin-Eintrag beweist keine lokale Ausführung.
