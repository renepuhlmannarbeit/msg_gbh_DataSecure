EU Privacy Document Gateway v3.2 RC1

Installation für Claude Desktop unter Windows – ohne CMD, PowerShell-Eingaben, Python oder npm-Installation durch den Anwender.

Was passiert lokal? Originaldatei → lokale De-Identifizierung → verifiziertes Markdown + nur freigegebene Grafiken → Claude liest ausschließlich Output.

1. Voraussetzung

Installiere/aktualisiere Claude Desktop für Windows. Für Unternehmensgeräte muss die IT Desktop Extensions erlauben.

2. Plugin installieren

  1. Claude Desktop öffnen.
  2. Einstellungen → Extensions → Advanced settings.
  3. Unter Extension Developer auf Install Extension… klicken.
  4. EU-Privacy-Document-Gateway-Windows-v3.2.0-rc1.mcpb auswählen.
  5. Installation bestätigen.

Alternative: Doppelklick auf die .mcpb-Datei, sofern Windows/Claude dies registriert hat.

3. Erster Funktionstest

In Claude schreiben:

Zeige mir den Privacy-Status.

Erwartet: Engine ready, runtime_dependency_install: false.

Dann:

Öffne meinen Privacy-Ordner.

Im Explorer erscheinen:

Claude Privacy\
  Input\
  Output\
  Processed\
  Needs Visual Review\

4. Dokument verarbeiten

  1. Nur eine Kopie des Dokuments nach Input legen.
  2. In Claude schreiben: Anonymisiere das nächste Dokument.
  3. Die Extension erkennt normalerweise automatisch Kunden-, Bewerber-, Mitarbeiterprofil- oder Vertragskontext.
  4. Das Ergebnis liegt als Paket in Output.
Output\Mitarbeiterprofil_..._anonymisiert\
  Mitarbeiterprofil_..._anonymisiert.md
  assets\
  manifest.json
  audit.json

5. Grafiken

Unsichere Bilder werden nicht an Claude weitergereicht. Sie erscheinen lokal unter Needs Visual Review.

Für Bewerber-/Mitarbeiterprofile werden Bilder standardmäßig zurückgehalten. Das verhindert insbesondere, dass ein Porträtfoto automatisch Teil der Claude-Analyse wird.

Wenn eine Grafik später gebraucht wird: in Claude Öffne den Visual-Review-Ordner sagen, Bild lokal prüfen und erst danach ausdrücklich freigeben.

6. Unterstützte Dateien

  • DOCX
  • XLSX
  • PPTX
  • PDF mit auslesbarem Textlayer
  • TXT, MD, CSV
Scan-/komplexe PDFs: Wenn kein sicherer Textlayer gelesen werden kann, stoppt die Verarbeitung. Das ist Absicht (fail-closed).

7. Datenschutz-/AI-Act-Hinweis

Die Extension ist ein technischer Datenschutzbaustein. Sie garantiert keine rechtliche Anonymität und zertifiziert keine EU-AI-Act-Konformität.

Bei Bewerber- oder Beschäftigtendaten muss der nachgelagerte Zweck separat bewertet werden. Ranking, Scoring, Filterung, Beförderungs-/Kündigungsentscheidungen, Monitoring oder bestimmte Aufgabenzuweisungen können regulatorisch anders einzuordnen sein als eine reine Kompetenzzusammenfassung.

8. Pilot-Abnahme

Vor breitem Rollout einmal auf einem Windows-PC testen:

  • DOCX Mitarbeiterprofil
  • XLSX Kundenliste
  • PPTX mit Grafik
  • PDF mit Textlayer
  • EMF/JPEG-Bild im Dokument

Wenn Windows-OCR/Rasterisierung nicht verfügbar ist, werden Bilder nicht automatisch freigegeben, sondern bleiben in der Review-Queue.
