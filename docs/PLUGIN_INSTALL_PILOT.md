# Plugin pilot installation

For the current public-repository pilot, use the CI-built `DataSecure-Privacy-Preflight-v3.2.0-rc2.zip` as a manual Claude plugin marketplace upload. The standalone `.mcpb` remains available for direct Claude Desktop Extension testing.

For organization-wide GitHub synchronization, change the repository to private/internal first, connect it under Organization settings > Plugins, and revalidate the marketplace sync before marking the plugin required or installed by default.
