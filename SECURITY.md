# Security Policy

## Sensitive data

This repository is public. Do not open issues, commits, pull requests, or test fixtures containing real employee, applicant, customer, contract, authentication, or other confidential data. Use synthetic examples only.

If a security issue could expose personal or confidential data, report it privately to the repository owner rather than posting exploitable details publicly.

## Design boundary

The gateway is designed to process originals locally and expose to Claude only verified Markdown and explicitly released visual assets. It is a technical privacy control, not a legal certification of anonymity, GDPR compliance, or EU AI Act compliance.
